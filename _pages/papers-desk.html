Sign in

The desk saves notes to lamng3/lamng3.com with a GitHub token that stays in this browser. Only an account that can push to the repository can save, so the page does nothing for anyone else.

  1. Create a fine-grained token: repository access Only select repositories, then lamng3.com; permissions Contents and Pull requests, both Read and write.
  2. Paste it here. It is kept in this browser only, until you sign out.
